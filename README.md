# Employee Management System – Frontend

## Project Overview
The Employee Management System is a full-stack web application frontend developed using React.js. It provides a user-friendly interface to manage employees and departments.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- Axios
- React Router DOM
- Vite

## Features
- View all employees
- Add new employees
- Update employee details
- Delete employees
- View all departments
- Add new departments
- Update department details
- Delete departments
- REST API integration with Spring Boot backend

## Project Structure
```text
ems-frontend/
├── public/
├── src/
│   ├── Components/
│   ├── Services/
│   ├── App.jsx
│   └── main.jsx
├── package.json
└── vite.config.js
```

## Backend Integration
The frontend communicates with the Spring Boot backend through REST APIs.

Backend URL: `http://localhost:8081`

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/sivabandaru31/ems-frontend.git
```

2. Navigate to the project:

```bash
cd ems-frontend
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
